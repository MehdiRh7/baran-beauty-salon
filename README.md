# سالن زیبایی باران — رابط کاربری React

رابط کاربری فارسی و واکنش‌گرای سامانه سالن زیبایی باران، شامل صفحه معرفی، اسلایدر، خدمات، تیم، رزومه و مدارک، گالری، تماس، فرایند رزرو چندمرحله‌ای و پنل مدیریت جامع.

## اجرا

```bash
npm install
npm run dev
```

## ساخت نسخه نهایی

```bash
npm run build
```

## محدوده نسخه فعلی

این نسخه فقط UI است. داده‌ها در حافظه مرورگر قرار دارند و آپلود فایل، رزرو و مدیریت روزهای غیرفعال برای نمایش تجربه کاربری شبیه‌سازی شده‌اند. اتصال دیتابیس، احراز هویت، ذخیره‌سازی فایل و پیامک در فاز بک‌اند انجام می‌شود.

تصاویر رابط کاربری این پروژه با ابزار تولید تصویر ساخته شده‌اند. لوگوی سالن از فایل ارائه‌شده توسط سفارش‌دهنده استفاده شده است.

## اتصال به API

این فرانت به ریپوی `baran-beauty-api` متصل است. آدرس API را می‌توان با متغیر زیر تنظیم کرد:

```env
VITE_API_URL=http://localhost:5077/api
```

ورود مدیر، خدمات، ثبت نوبت، فهرست نوبت‌ها و کتابخانه رسانه از API خوانده یا در آن ذخیره می‌شوند.
