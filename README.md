# سالن زیبایی باران — رابط کاربری React

قالب فارسی و واکنش‌گرای سامانه سالن زیبایی باران، شامل صفحه معرفی، اسلایدر، خدمات، تیم، رزومه و مدارک، گالری، تماس، فرایند رزرو چندمرحله‌ای و پنل مدیریت نمایشی.

## اجرا

```bash
npm install
npm run dev
```

## ساخت نسخه نهایی

```bash
npm run build
```

## محدوده نسخه فعلی

این نسخه فقط UI است. داده‌ها در حافظه مرورگر قرار دارند و آپلود فایل، رزرو و مدیریت روزهای غیرفعال برای نمایش تجربه کاربری شبیه‌سازی شده‌اند. اتصال دیتابیس، احراز هویت، ذخیره‌سازی فایل و پیامک در فاز بک‌اند انجام می‌شود.

تصاویر نمایشی این پروژه با ابزار تولید تصویر ساخته شده‌اند. لوگوی سالن از فایل ارائه‌شده توسط سفارش‌دهنده استفاده شده است.
